# 5.5 常用算数生成算法

**注意：**

- 算数生成算法属于小型算法，使用时包含的头文件为`#include <numeric>`

**算法简介：**

- `accumulate`//计算容器元素累计总和
- `fill`//向容器中添加元素

## 5.5.1 accumlate

**计算区间内 容器元素累计总和**

**函数原型：**

- `accumulate(iterator beg, iterator end, value);`

  //计算容器元素累计总和

  //value 起始累加值
  
  ```c++
  void test01() {
      vector<int> v;
      for(int i = 0; i <= 100; i++) {
          v.push_back(i);
      }
      int total = accumulate(v.begin(), v.end(), 0);
  }
  ```
  

## 5.2.2 fill

- 向容器中填充指定元素

**函数原型：**

- `fill(iterator beg, iterator end, value);`

  //向容器中填充元素

  //value 填充的值

**示例：**

```c++
void test01() {
    vector<int> v;
    v.resize(10);
    
    fill(v.begin(), v.end(), 100);
    
}
```
