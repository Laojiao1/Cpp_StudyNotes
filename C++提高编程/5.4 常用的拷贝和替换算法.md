# 5.4 常用的拷贝和替换算法

**学习目标：**

- 掌握常用的拷贝和替换算法

**算法简介：**

- `copy` //容器内指定范围的元素拷贝到另一容器中
- `replace`//将容器内指定范围的就元素修改为新元素
- `replace_if`//容器内指定范围满足条件的元素替换为新元素
- `swap`//互换两个容器的元素

## 5.4.1 copy

**功能描述：**

- 容器内指定范围的元素拷贝到另一个容器中

**函数原型：**

- `copy(iterator beg, iterator end, iterator dest);`

  //按值查找元素，找到返回指定位置的迭代器，找不到返回结束迭代器位置

**示例：**

```c++
void print(int val) {
    cout << val << endl;
}

void test01() {
    vector<int> v1;
    for(int i = 0; i < 10; i++) {
        v1.push_back(i);
    }
    
    vector<int> v2;
    v2.reset(v1.size());
    copy(v1.begin(), v1.end(), v2.begin());
    for_each(v2.begin(), v2.end(), print());
}
```

## 5.4.2 replace

- `replace(iterator beg, iterator end, oldvalue, newvalue);`

  //将区间内旧元素替换成新元素

**示例：**

```c++
void test01() {
    vector<int> v;
    v.push_back(10);
    v.push_back(50);
    v.push_back(40);
    v.push_back(20);
    v.push_back(30);
    v.push_back(20);
    
    //替换前
    //10 50 40 20 30 20
    
    
    //替换后(20->2000)
    replace(v,begin(), v.end(), 20, 2000);
    //10 50 40 2000 30 2000
}
```

## 5.4.3 replace_if

**功能描述：**

- 将区间内满足元素的条件，替换成指定元素

**函数原型：**

- `replace_if(iterator beg, iterator end, _pred, newvalue);`

  //按条件替换元素，满足条件的替换成指定元素

**示例：**

```c++
class Greater30 {
    public:
    void operator()(int val) {
        return val >= 30;
    }
}

void test01() {
    vector<int> v;
    v.push_back(10);
    v.push_back(50);
    v.push_back(40);
    v.push_back(20);
    v.push_back(30);
    v.push_back(20);
    
    //将大于等于30的数替换为3000
    replace_if(v.begin(), v.end(), Greater30(), 3000);
}
```

## 5.4.4 swap

**功能描述：**

- 互换两个容器元素

**函数原型：**

- `swap(container c1, container c2);`

  //互换两个容器的元素

**示例：**

```c++
void test01() {
    vector<int> v1;
    vector<int> v2;
    for(int i = 0; i < 10; i++) {
        v1.push_back(i);
        v2.push_back(i+100);
    }
    swap(v1, v2);
    
}
```
